About this library

This is your central index of documents — not file storage. Each entry holds a title, category, tags, description and a link to where the file actually lives (Google Drive, Notion, OneDrive, etc). Native file uploads need Supabase Storage which is pending Dean's config. When that lands, an Upload button replaces the “Link to” field.
