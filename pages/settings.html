People & roles Loading…
Three roles control what each person can see:
  • Owner — Lewis & Dean. Sees everything, manages roles here.
  • Lead — Anyone with leadership / budget remit. Sees Finance, Strategy, Investor, and all sensitive fields (cash, runway, MRR).
  • Member — Default for the team. Sees the operating hub (CRM, Tasks, Action Plans, Content, Sessions) with sensitive financial fields redacted.
  • External — Advisors / contractors. Read-only, limited to Brief, Dashboard, Strategy, Investor, Documents.
Note: This is client-side enforcement only. Suitable for an internal trusted team but not a security boundary against a determined attacker. Real enforcement will mirror this model in Supabase Row Level Security (Dean to wire).
